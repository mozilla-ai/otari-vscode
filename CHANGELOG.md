# Changelog

## 0.1.2

First preview.

- Otari models in VS Code chat, with tool calls, request tags and the cost of each response in the status bar.
- Sign-in to otari.ai, its EU region or your own gateway, with the key in VS Code's secret storage.
- One command to route Claude Code, Codex and OpenAI-compatible agents through Otari, and to stop.
- Agent Guardrails findings in Problems on save, plus dry run, change checks, hook setup and generation.
